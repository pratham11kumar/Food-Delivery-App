🍔 Food Delivery App (React Native)

A modern Food Delivery mobile application built using React Native.
It includes restaurant browsing, food details, cart functionality, and full navigation flow.

🚀 App Features
🏠 Home screen with restaurant list
🍽️ Restaurant detail screen
🥘 Food item detail screen
🛒 Cart screen
📦 Order flow UI
🔀 Stack + Tab Navigation
🧭 Navigation Structure
📊 Diagram
Bottom Tab Navigator
│
├── Home (Stack Navigator)
│     ├── Restaurant List Screen
│     ├── Restaurant Detail Screen
│     ├── Food Detail Screen
│     └── Cart Screen (hidden in tab when active)
│
├── Cart Screen
└── Profile Screen
📌 Navigation Flow Explanation
Home tab contains a Stack Navigator
User moves from Restaurant → Food → Cart
Cart screen is accessible from both Stack and Tab
Tab bar hides automatically on detail & cart screens
Smooth navigation handled using React Navigation v6
🛠️ Tech Stack
React Native
React Navigation
Context API
JavaScript
